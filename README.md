A lightweight desktop ticket management application built with **Python** and **CustomTkinter**.

Features include:

- 🎫 Ticket creation and management
- 🔎 Real-time search
- ✏️ Ticket editing
- 🗑️ Ticket deletion
- 📝 Ticket notes
- 🏷️ Tags and priorities
- 📊 Ticket statuses
- 💾 Local JSON data storage
- 🌙 Dark GUI
